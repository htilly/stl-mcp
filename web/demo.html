See it in action

A real session, sped up 4×: Claude on claude.ai on the right, the live 3D view on the left. A handful of short messages take an ESP32 dev board box from nothing to printable.

  1. "make a box for a ESP32 dev board. Add the text esp32 on the side of the box." Body, friction-fit lid and engraved text.
  2. "now add screws to the box so I can make the lid solid" Four M3 corner posts in the body, countersunk holes in the lid.
  3. A comment clicked on the side of the box, "write the text autoSMITH centered here". Engraved exactly there.
  4. "I did not find the screws?" Four printable M3 screws as a separate part, checked for thin walls and overhangs.
  5. "did you adjust the holes so that the screws will be able to 'screw'?" Claude checks the holes against the printed threads.

Every step shows up in the 3D view as soon as Claude makes it, and each one is a version you can go back to.
