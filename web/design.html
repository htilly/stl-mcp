Design system

The colours, text styles, fonts, icons and components the web UI is built from. Every value on this page is read from the live style.css and icons.svg, so it shows what is deployed. The written rules are in docs/DESIGN.md.

Colour

Neutral metal greys for the workbench, layout blue for the one thing that matters on a screen, build-plate gold for comments. Switch the theme to see the dark values.

Icons

24 × 24 grid, 1.6 stroke, round joins, coloured by the surrounding text. Use <svg class="i"><use href="/static/icons.svg#i-name"/></svg> or icon("name").

Space and shape

A 4 px grid. Two radii: 4 px for controls, 6 px for panels. One shadow, only for things that float.
