Get started

Claude builds the models; this page shows them, live, with every revision.

  1. Account created
  2. Add a passkeySo you can log in with one tap, and approve Claude when you connect it.
  3. Connect ClaudeAdd this library to claude.ai, ChatGPT or Claude Code.
  4. Ask for a partIn plain words, for example:
    Make a box 80 × 50 × 25 mm with a lid and a USB-C hole on the short side.
    It shows up here as soon as Claude builds it, and updates every time Claude changes it.

      claude.ai and the Claude apps
      1. In claude.ai, open Settings → Connectors and click Add custom connector.
      2. Name it autosmith, paste the address above, leave the advanced settings empty and click Add.
      3. Click Connect. A page from this library opens; log in with your passkey if asked.
      4. Check that it sends you back to https://claude.ai, then click Allow.
      5. In a chat, turn the connector on in the tools menu and ask Claude for a model.
      ChatGPT
      1. In ChatGPT, open Settings → Apps & Connectors → Advanced settings and turn on Developer mode (on some plans an admin has to allow it).
      2. Click Create, name it autosmith, paste the address above and choose OAuth as authentication. Leave client id and secret empty.
      3. A page from this library opens: log in with your passkey and click Allow.
      4. In a chat, turn the connector on and ask for a model.
      Claude Code and Claude Desktop
      1. Create a personal token below.
      2. Run the command shown with it.
